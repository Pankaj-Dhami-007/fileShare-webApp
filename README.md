# 🌐 FileShare Web App

A complete **File Manager Web Application** built with **React**, **Spring Boot**, **MongoDB**, and **Tailwind CSS** — designed to help you manage, share, and access your files seamlessly.

This project combines **frontend + backend integration**, **secure authentication**, and a **modern responsive UI** to give a professional-grade file management experience.

## 💡 What You’ll Learn / Build

With this project, you'll learn to:

- 📤 Upload, preview, download & delete files  
- 🔐 Toggle files between **public/private** visibility  
- 🔗 Share **public files** via unique links  
- 🧩 View files in **grid or list mode** with a beautiful, responsive UI  
- 👥 Implement **user-based file access** using **Clerk authentication**  
- 🎨 Build modern UI using **Tailwind CSS** and **Lucide icons**  
- 🧱 Follow clean, reusable code structure (e.g. `FileCard`, `FileListRow`, etc.)
